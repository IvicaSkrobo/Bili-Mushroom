# Quick Task 260821 — Croatian collation whitespace parity

## Objective

Close the remaining backend/frontend ordering mismatch for species names containing Unicode whitespace. Rust currently assigns the low whitespace/punctuation class only to ASCII space (`' '`), while TypeScript treats every trim-empty whitespace character the same way. Make Rust use Unicode whitespace semantics and lock TAB/NBSP ordering across adjacent SQL pages to the existing frontend contract.

## Existing contract

- `compare_croatian_species_names` backs the `BILI_HR` SQLite collation used before `LIMIT/OFFSET`; it must remain a deterministic total order.
- `compareSpeciesNames` in `src/lib/speciesName.tsx` already classifies TAB and NBSP as whitespace through `character.trim().length === 0`. That frontend implementation is the expected behavior and does not need modification.
- Croatian alphabet weights, digraph handling, `*` stripping, punctuation handling, Unicode search, page size, and UI behavior are already covered by the preceding task and must remain unchanged.

## Task — Treat all Unicode whitespace identically and test a real page boundary

**Files:** `src-tauri/src/commands/import.rs`

**Action:**

- In `croatian_sort_tokens`, replace the ASCII-only `character == ' '` condition with Rust `character.is_whitespace()`, retaining the existing ASCII-punctuation branch and token weight/value representation. Do not normalize, collapse, or delete whitespace: TAB and NBSP must keep their own code-point tie-break values just as TypeScript does.
- Extend `collection_folder_alpha_sort_happens_before_pagination` with otherwise-near-identical species names containing ASCII space, TAB (`\t`), and NBSP (`\u{00A0}`). Derive the expected fixture from the current frontend comparator semantics: all three belong to the same low token class, then order by their code point (`TAB` before ASCII space before NBSP) before subsequent letters.
- Place the whitespace variants on opposite sides of an intentionally small page boundary. Fetch at least two adjacent alpha pages, concatenate them, and assert exact expected order with no duplicates or omissions. Repeat the assertion for equal-date recent ordering because it uses the same Croatian secondary collation.
- Add a direct comparator assertion if useful for diagnosis, but keep the paginated command regression as the acceptance test: it proves the registered SQLite collation, grouped ordering, and `LIMIT/OFFSET` wiring—not merely the pure helper.
- Mutation-check the regression by temporarily restoring `character == ' '`: the TAB/NBSP page-order assertion must fail, then restore `is_whitespace()`.

**Verify:**

- Automated: `npm run test:rust -- collection_folder_alpha_sort_happens_before_pagination`
- Automated safety net: `npm run test:rust -- collection_folder`
- Confirm no TypeScript/source UI file changed and `git diff -- src/lib/speciesName.tsx` is empty.

**Done:** Rust and TypeScript assign TAB, ASCII space, and NBSP the same token class and produce one identical deterministic order; adjacent Collection pages concatenate without a reordered, duplicated, or missing species.
